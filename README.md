# UniDay

Telegram-бот для просмотра расписания ВГЛТУ и напоминаний в учебные дни.

Помогает узнать расписание на сегодня, завтра и ближайшие семь дней, исключить занятия, которые не нужно посещать, и настроить напоминания - например, когда поесть или выйти на учёбу

## Возможности

- Регистрация с указанием группы и подгруппы
- Просмотр расписания на сегодня, завтра и семь дней
- Исключение занятий из расписания
- Текстовые напоминания и автоматическая отправка расписания.
- Напоминания в фиксированное время или до первой пары
- Изменение группы и подгруппы через профиль
- Управление через команды и кнопки меню
- Кэширование расписания в памяти на один час

## Стек

- Python
- aiogram
- httpx
- BeautifulSoup
- aiosqlite
- Pydantic Settings.

Данные пользователей, исключённые занятия и напоминания хранятся в SQLite. Расписание загружается с сайта ВГЛТУ и разбирается из HTML

## Запуск

Для установки зависимостей используется [uv](https://docs.astral.sh/uv/).

1. Клонируйте репозиторий и перейдите в его каталог:

   ```bash
   git clone https://github.com/banana-whyyy/UniDay.git
   cd UniDay
   ```

2. Установите зависимости:

   ```bash
   uv sync
   ```

3. Создайте файл `.env` с токеном бота и настройками из конфигурации проекта. Токен можно получить у [@BotFather](https://t.me/BotFather).

   Не публикуйте `.env` и токен в репозитории.

4. Запустите бота:

   ```bash
   uv run python -m uniday.main
   ```

База данных и таблицы создаются при первом запуске. Каталог для файла SQLite должен существовать.

## Использование

Отправьте `/start`, укажите группу, например `ИС2-251-ОБ`, и выберите подгруппу.

После регистрации доступны кнопки:

- **Сегодня** — расписание на текущий день
- **Завтра** — расписание на следующий день
- **Неделя** — расписание на семь дней, начиная с текущего
- **Меню** — исключённые занятия, напоминания и профиль

В профиле можно изменить группу и подгруппу.

## Напоминания

Напоминание может содержать собственный текст или расписание на сегодня, завтра либо неделю

Доступны два режима:

- В фиксированное время по Москве
- За указанное количество минут до первой пары

Напоминания отправляются только в дни, когда есть занятия после применения исключений. Время первой пары также рассчитывается с учётом исключённых занятий

Бот проверяет напоминания каждые 30 секунд. Допустимое опоздание составляет одну минуту: более старые напоминания не отправляются

Дата отправки сохраняется в SQLite, чтобы повторные проверки и перезапуски не приводили к обычной повторной отправке

## Особенности и ограничения

- Все даты и время рассчитываются по московскому времени
- Расписание зависит от доступности сайта ВГЛТУ и структуры его HTML
- Изменения расписания могут появляться с задержкой до одного часа из-за кэширования
- Кэш хранится в памяти и сбрасывается при перезапуске
- Напоминания работают, пока процесс бота запущен
- Запускайте один экземпляр бота, чтобы избежать конфликтов polling и повторных отправок
- Напоминания со смещением на предыдущий календарный день пока не поддерживаются
- Проект не является официальным сервисом ВГЛТУ
