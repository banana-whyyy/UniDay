# UniDay

Telegram-бот, который поможет планировать учебный день: покажет расписание, напомнит, когда выходить на занятия.

Сейчас реализован парсер расписания ВГЛТУ. Он преобразует HTML сайта в данные по дням и занятиям, учитывая общие пары и подгруппы. Бот, сохранение настроек и напоминания находятся в разработке

## Стек

- Python 
- BeautifulSoup
- aiogram
- httpx
- aiosqlite

## Источник расписания

Данные берутся с [сайта расписания ВГЛТУ](https://kis.vgltu.ru/schedule).
